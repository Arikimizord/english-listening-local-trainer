# 本地导入示范：四级 2026-06 第 1 套听力

本仓库不包含这套真题音频、识别文字、JSON 或 SRT。请自行准备有权使用的原始录音；项目代码的 MIT 授权不涵盖真题。

1. 按 docs/INSTALL.md 配置字幕工作台，再打开字幕工作站.cmd。
2. 拖入你本机的这一套录音，或填写其完整本地路径；每次处理一份音频。
3. 生成字幕后点击“试听与修订”，检查句子、断句和词级时间；修改后保存独立修订，必要时重新对齐。
4. 下载课堂包，在本机解压；保留音频与同名 JSON、SRT 的相对位置和名称。修订界面的独立导出需手动与音频配对。
5. 打开 offline-player/dist/听力课堂.exe 并拖入音频。优先加载同名 JSON，SRT 用于普通字幕回退。
6. 在实际使用电脑验证播放、逐词高亮、选词、切句、单句循环和句末暂停。

自行录制或另有使用权的英文材料同样适用上述流程，不要求只能用真题。不公开上传你生成的真题字幕或课堂包；这些本地文件由 .gitignore 排除。

目录示意（仅说明，不附实际文件）：

```
你的本地课堂素材/
  四级_2026-06_第1套_听力.mp3
  四级_2026-06_第1套_听力.json
  四级_2026-06_第1套_听力.srt
```

普通 UTF-8 SRT 不具备真实词级对齐信息；请勿用均分单词时间冒充真实词轴。
