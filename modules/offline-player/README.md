# 离线专用播放器 · 听力课堂

这是为英语课堂和个人精听设计的轻量 Windows 播放器。你可以隐藏字幕盲听、逐句重听、调速、循环一句，或在句末自动暂停。它只负责播放，不会现场调用 AI，也不会生成字幕。

## 下载后怎么用

1. 找到本目录 `dist/听力课堂.exe`，双击打开；加载完成后进入界面。
2. 拖入本地音频，或点击“打开音频”。已有音频也能直接播放，不强制安装字幕工作台。
3. 音频旁放同名 JSON 或 SRT，程序会自动加载；优先 JSON，也可以点击“选择字幕”。JSON 需要由工作台生成真实词轴，普通 SRT 仅提供句级字幕。

例如 `lesson.mp3`、`lesson.json`、`lesson.srt` 放在同一文件夹。复制到教室电脑时把这些文件一起带上，EXE 可单独放在方便的位置。

不需要 Python、模型、独立显卡或联网。需要 Windows 10/11 x64 的 .NET Framework 4.x/WPF 与媒体组件；精简系统和 Windows N 版需检查组件。教室老电脑兼容性仍应在上课前实测。

## 常用操作

- 空格：播放/暂停；左右方向键：上一句/下一句并播放。
- H：显示/隐藏字幕；切句不会把隐藏字幕自动显示出来。
- 单句循环与句末暂停互斥；句末暂停后继续播放会进入下一句。
- 进度条、±15 秒用于定位；速度、音量、A−/A+ 调整听感和字幕字号。
- F11 全屏，Esc 退出；暂停后可拖选字幕、双击选词、Ctrl+C 复制。

没有字幕时，切句、句末暂停和单句循环无法按句子工作。词级高亮需要匹配录音的 JSON。设置与播放位置只保存在当前用户本机，不修改原音频和字幕。

## 需要自己制作字幕？

到 [本地字幕工作台](../subtitle-workstation/README.md)，在有兼容 GPU 的制作电脑生成并试听修订，再把课堂包复制过来。不需要让教室电脑承担模型部署。

源码使用系统 .NET Framework 编译器构建：运行本目录 `build.ps1`。普通用户直接用 EXE，无需编译。
