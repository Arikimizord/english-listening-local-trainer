# 本地字幕生成工作台

这是在你自己的电脑上，把英文录音制作成可试听、可修改、带词级时间轴的课堂字幕的工具。适合需要准备听力课的教师，以及想为自有录音制作精听字幕的学习者。

它负责“制作”，不必安装到教室电脑；制作好的音频、同名 JSON 和 SRT 可以复制给另一个模块的离线播放器。

## 首次准备

需要 Windows x64、兼容的 NVIDIA GPU 和驱动；当前固定方案在约 8 GB 显存的作者电脑验证过。建议有 40 GB 可用空间容纳环境、模型分卷、合并与解包临时文件。首次需联网下载多 GB 文件，之后生产音频本机处理。

推荐把根 README 开头的一句话发给自己的本地 Agent。手动操作也可以：在仓库根目录打开新的 PowerShell，运行：

```powershell
powershell -NoProfile -File ./modules/subtitle-workstation/setup.ps1
```

默认从本仓库的 [models-v1 Release](https://github.com/Arikimizord/english-listening-local-trainer/releases/tag/models-v1) 下载四个固定分卷，校验分卷、整包及各模型文件，自动安装，不需要自己挑选模型版本。安装器另行下载固定 Python、依赖和 FFmpeg；模型包不等于完整运行环境。

网络慢时可先手动下载四个分卷至同一目录，再在上述命令后加 `-ModelBundleDirectory "你的分卷文件夹绝对路径"`。不要独立解压某一卷。详细条件、上游固定版本备用安装方法见 [安装说明](../../docs/INSTALL.md)。

## 每次使用

1. 双击本目录 `字幕工作站.cmd`，保持启动窗口运行。
2. 在自动打开的本机网页拖入英文音频，或填写其本地路径。
3. 点击“开始生成字幕”，等待识别、校验、词级对齐完成。
4. 点击“试听与修订”，逐句检查文字、断句和时间，修改后保存；必要时重新对齐。
5. 下载课堂包，解压后把音频和同名 JSON/SRT 一起交给离线播放器。

失败时先查看日志，可取消、恢复任务；不要手动修改任务状态。旧网页地址失效时重新启动并使用新网址。不会自动上传录音，但安装阶段会联网下载依赖。

## 请注意

自动结果需要人工试听，生成完成不等于全部正确。首次安装脚本已做语法和模型导入验证，但尚未在全新电脑验证整套 GPU 环境。没有兼容 GPU 时停止并查看提示，不自动换小模型或 CPU。

更多操作见 [使用指南](../../docs/USAGE.md)；示范仅提供 [本地导入方法](../../examples/README.md)，不附真题录音与字幕。代码 MIT，品牌和原创美术保留权利，第三方模型适用各自许可证。
