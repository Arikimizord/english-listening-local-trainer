- model-bundle-v1.json 固定四个分卷、整包及内部模型/资源校验值。打包时逐一匹配旧模型锁的 revision、大小、SHA-256/Git blob SHA-1，不包含模型目录的 .cache、锁文件或本机元数据。

- 模型包的英文 NLTK 资源可从包内安装。新模型下载器和安装器的 Python 语法、更新后的 setup.ps1 语法通过。下载器网络续传与全新 GPU 电脑端到端安装仍待验证。
- 根 README 提供给本地 Agent 的自然语言部署指令；AGENTS.md 明确部署前检查、授权范围与失败停止规则。这不是额外 Agent 托管服务，也不是所有电脑均已验证的无人值守部署承诺。
