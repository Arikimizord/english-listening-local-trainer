# 从备课到精听

## 字幕工作台：在制作电脑上完成

1. 双击 modules/subtitle-workstation/字幕工作站.cmd。
2. 拖入英文音频（MP3/M4A/WAV/AAC，单文件最大 2 GB），或展开本地路径选项。导入会创建本机副本；直接路径可省去导入副本。
3. 点击开始生成，阶段依次为识别与校验、词级对齐、字幕成品。阶段显示不等于连续百分比，也不代表人工审核。
4. 点击试听与修订：逐句播放、改文字、改时间，必要时单句重对齐并保存独立修订。改文字后旧词轴失效，不能把旧轴配新文字。
5. 下载课堂包或从修订页导出；确认音频、同名 JSON、SRT 配对。复制到教室前试听。

可取消正在运行的任务并从恢复入口继续；不手动编辑 job.json。人工修订和历史成品独立保留，不会因普通重跑自动批准或覆盖。取消/恢复异常时查看日志，避免强杀未知进程。

## 离线播放器：在教室或学习电脑上使用

三秒猫鼠启动动画结束后拖入音频。同名 JSON 优先自动加载；没有 JSON 时寻找 SRT，也可手动选择字幕。纯音频仍能播放。JSON 词轴需与音频匹配，不把字幕时间均分成假词轴。

| 操作 | 功能 |
|---|---|
| 空格 / 播放按钮 | 播放、暂停 |
| 左右方向键 / 上一句、下一句 | 切句并播放 |
| H / 显隐按钮 | 切换字幕，切句不自动揭示隐藏字幕 |
| 单句循环 / 句末暂停 | 两者互斥；句末暂停后播放会进入下一句 |
| ±15 秒 / 进度条 | 定位音频 |
| 速度 / 音量 / A−、A+ | 倍速、音量与字幕字号 |
| F11 / Esc | 全屏、退出全屏 |
| 字幕拖选或双击 / Ctrl+C | 选择或复制单词 |

操作滑块和下拉框时键盘优先作用于控件。设置及播放位置保存在当前用户 LocalAppData/CETClassroomPlayer/state.xml，不写入 Git；不要上传这些个人使用记录。

## 上课前检查

在真实教室电脑确认有声播放、切句、循环、句末暂停、字幕隐藏、字号和全屏。生成字幕必须试听；模型成功返回不是精度保证。播放器无法解码时在制作端检查真实容器/编码，不用改扩展名假装转码。
